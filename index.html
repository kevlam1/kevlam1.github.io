Artifact 1 · My Portfolio · Due Oct 11 Live

Personal Portfolio

A single-page portfolio with a card for each artifact in the course, built with plain HTML, CSS, and JavaScript.

HTML CSS JavaScript WebGL GitHub Pages Claude

I built this portfolio with Claude's web chat and deployed it on GitHub Pages, which I had never set up before. Early on, Claude jumped ahead and built a theme-comparison page before I understood hosting, so I stopped it and we learned the deployment steps first. I also had to clarify my card layout a few times before it matched what I pictured. The biggest thing I learned is to describe the exact layout I want, and to check what the AI tells me against the real documentation instead of trusting it. Whenever I hit Claude's limits, I switched to ChatGPT and Gemini, but I found their quality lacking compared to Claude, and they were sometimes close to useless. Still, the way I had to phrase my requests for them taught me to ask Claude more clearly, which brought out better code.

Side Projects

Pokémon TCG Database Live

Cardex

A Pokémon TCG collection companion. Search cards, track and wishlist what you own, and see TCGPlayer prices and your collection's total value, with a Pokédex and set tracking.

Next.js React Node.js Supabase REST API OpenAPI Vercel Render

This was the first project a partner and I started over the summer after our TCSS 460 class, which simulated building a site for a client using server programming. We wanted to apply those skills while learning to make something without the guidance of an instructor. Using APIs, Next.js, React, optimization practices, and the structure we learned in that class, we created Cardex. I primarily focused on the user experience and on optimizing resource management.

Pokémon Guess Who Live

PokéGuess

A multiplayer Pokémon take on the board game Guess Who. Create a room, share the link with a friend, ready up, and play with live chat once the game starts.

Next.js React Express WebSockets AWS DynamoDB Docker AWS EC2 Vercel

PokéGuess was the next project I started over the summer, and a chance to keep building on what I'd learned from Cardex. I again focused on the user experience and optimization, this time across both the backend and frontend, along with the UI and visuals. Building it from the ground up pushed me to hone my skills and keep learning as I went. It also showed me how much communication and collaboration matter: talking through ideas and solving problems together were a big part of bringing it to life. It was rewarding to see our ideas come together as a live, playable experience.
